# home-banking-login-java
Aplicación de consola en Java que simula el ingreso a un home banking. Para entrar hay que ingresar usuario, contraseña y un token aleatorio de un solo uso. Si los datos son incorrectos, se puede reintentar hasta un máximo de tres veces, y después el usuario queda bloqueado.

Es un proyecto de práctica que hice para aplicar lo que aprendí en el curso de Introducción a Java.
